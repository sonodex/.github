# Security

## Reporting a vulnerability

Please do **not** report security issues as a public issue, pull request or discussion. Email **[support@sonodex.zxp.wtf](mailto:support@sonodex.zxp.wtf)** with the subject "Security: …".

Helpful details:

- affected version (About dialog or diagnostics) and operating system;
- affected part: desktop app, native helpers, extensions/SDK, account and share server, or website;
- steps to reproduce and the possible impact;
- no real credentials, libraries or music files; use synthetic test data where needed.

We confirm receipt, review the report and get back to you with next steps. Please do not disclose the issue before a fix is available or we have agreed on a date.

## Supported versions

Security fixes ship for the current version (the latest release). Please check that the issue still exists there before reporting.
